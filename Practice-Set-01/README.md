# C++ Practice Set 01

Ten small programs for moving from C to C++.

## Problems

1. Full name information using `string` and `getline`
2. Count vowels in a line
3. Reverse a string
4. Swap two numbers using references
5. Update a value using a reference parameter
6. Read and print a `vector`
7. Calculate vector sum and average
8. Find the largest value in a vector
9. Sort a vector
10. Linear search in a vector

## Topics Practiced

- `cin`, `cout`, and `getline`
- C++ `string`
- References
- Functions
- `vector`
- Range-based loops
- `sort()`
- Basic searching

Compile a file with:

```bash
g++ filename.cpp -o program
```

Run it on Windows PowerShell with:

```powershell
.\program.exe
```
