DSA Day 01 - Array Problems

Today I practiced some basic array problems in C++.

I solved 5 problems to understand how array traversal, searching, swapping and value comparison work.

Problems I Solved
1. Array Sum and Average

In this problem, I took some numbers in an array and calculated their total sum and average.

2. Find Maximum and Minimum

Here, I checked every element of the array and found the largest and smallest numbers.

3. Reverse an Array

I reversed the array using two pointers. One pointer started from the beginning and another one started from the end.

4. Linear Search

In this problem, I searched for a specific number inside the array. If the number was found, the program showed its index.

5. Second Largest Distinct Element

Here, I found the second largest different number without sorting the array.
