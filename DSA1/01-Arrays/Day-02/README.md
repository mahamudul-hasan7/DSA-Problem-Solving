DSA Day 02 - Array Problems

Today I continued my basic array practice in C++.

Day 01 was about input, traversal, max/min, reverse and linear search.
Day 02 stays close to that level and adds a few simple array operations.

Problems I Solved
1. Remove Duplicates from a Sorted Array

In this problem, I removed repeated values from a sorted array and kept only the unique elements.

2. Rotate Array by One

Here, I shifted every element one position to the right and moved the last element to the front.

3. Move Zeroes to the End

In this problem, I moved all zero values to the end while keeping the order of non-zero elements.

4. Count Occurrences of a Target

Here, I counted how many times a specific value appears in the array.

5. Find Missing Number

In this problem, I found the missing value from an array containing numbers from 1 to n.
